# Identidad visual

Coloca aquí los archivos del canal:

- `logo.png`: icono de la ventana y ruta sugerida para **Logo / CG (RTMP)**.
- `logo.ico`: icono del ejecutable Windows durante el empaquetado.

Los dos archivos son opcionales. No se incluye un logo de ejemplo para no
sustituir la identidad visual del operador.
