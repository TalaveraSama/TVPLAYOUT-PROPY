# Nexora Air V25.5.0 — Cobertura de pruebas de `fmt_tc`

## Resumen

Release de mantenimiento: incorpora el PR de cobertura de tests pendiente
(`test/cobertura-fmt-tc`) sobre `app/widgets.py::fmt_tc`, la utilidad de
formato de timecode usada en toda la interfaz (playlist, reloj de estación,
as-run log) y en la salida.

## Cambios

- **Tests**: se añaden asserts en `tests/test_core.py::test_fmt_tc` para tres
  comportamientos que no tenían cobertura explícita:
  - Entrada `None` → devuelve `"00:00:00"` en vez de fallar.
  - `show_hours=False` → omite las horas cuando son cero (`"01:05"`), pero las
    muestra igual si `h > 0` (`"01:01:01"`).
  - `frames=True` con `fps` explícito → agrega el sufijo de cuadros
    (`"00:00:01.05"` para 1.5 s a 10 fps).
- **Sin cambios en código de producción**: `fmt_tc` no se modificó; los casos
  nuevos documentan y congelan el comportamiento ya existente.

## Validación

- Suite completa verde salvo los mismos módulos que ya requerían un entorno
  gráfico (Qt/`libGL`) no disponible en CI headless — sin regresiones
  respecto a V25.4.0.
