# Nexora Air V25.7.0 — preparación del motor OBS embebido

## Novedades

- **Arquitectura de motor seleccionable:** se prepara la evolución de Nexora
  hacia un backend `libobs` embebido, manteniendo FFmpeg como motor estable y
  fallback durante la transición.
- **RTMP/RTMPS, SRT y UDP:** se documenta la ruta de integración OBS para las
  salidas de emisión. NDI requiere su plugin y runtime específico, por lo que
  no se presenta como parte del OBS Studio oficial.
- **Instalador reproducible:** la versión V25.7.0 queda sincronizada entre la
  aplicación, documentación, launchers y herramientas de release.

Esta es una release de preparación. El runtime Windows de OBS/libobs se
incorporará al instalador cuando finalice su compilación reproducible y sus
pruebas de compatibilidad.

## Comprobación

```bash
python3 tools/prepare_release.py --check
python3 installer/build_windows_setup.py check
```
