# TVPlayout PRO V22.2.9

## Bug 1: el playout no avanza cuando un clip termina

El usuario reportó "no avanza la playout". En la imagen se veía
POSICIÓN 00:03:58 vs DURACIÓN 00:03:07 — la posición estimada
superaba la duración pero el playout no cambiaba al siguiente clip.

**Causa**: en algunas builds de mpv, el evento `end-file` no se
emite por IPC cuando el clip termina. El playout depende de ese
evento para llamar `_on_ended("eof")` y avanzar. Sin el evento,
queda colgado en el último frame aunque la posición estimada
(calculada con `_started_at`) haya pasado la duración.

**Fix**: `_tick()` (que corre cada 500ms) ahora tiene un watchdog
que llama `_on_ended("eof")` cuando `elapsed > duration + 2s`.
Delay máximo entre el fin real del clip y la detección: 2.5s.

```python
def _tick(self):
    if self.is_on_air and not self.paused and self.duration > 0:
        pos = float(self.elapsed or 0.0)
        if pos > self.duration + 2.0:
            log.warning("Watchdog fin de clip: %.2fs > %.2fs", pos, self.duration)
            self._on_ended("eof")
            return
    # ... resto del _tick ...
```

## Bug 2: el VU meter no se anima, 105 warnings

El usuario reportó "sonido igual" y vio "105 warnings" en el
statusBar. La causa raíz estaba en el formato del filtro VU:

**Antes** (v22.2.5):
```
VU_FILTER = "@vu:lavfi=[astats=...:measure_perchannel=Peak_level:...]"
keys: lavfi.astats.1.Peak_level, lavfi.astats.2.Peak_level
```

**Ahora** (v22.2.9, mpv 0.40+):
```
VU_FILTER = "@vu:lavfi=astats=metadata=1:reset=1"
keys: lavfi.astats.Overall.Peak_level, lavfi.astats.Overall.RMS_level
```

El formato viejo (con corchetes) y las keys `.1.`, `.2.` no existen
en builds nuevos de mpv. El filtro se creaba pero las keys no se
encontraban, así que el VU siempre leía -inf y se generaban warnings
repetidos.

**Fix**: formato nuevo de filtro + keys nuevas. El VU debería animarse
en mpv 0.41+ (el binario que tenés ahora).

## Cómo actualizar

1. `git pull origin arena/01a07acb-tvplayout-propy`
2. `build_exe.bat` (o re-ejecutá con `python main.py`)
3. Reemplazá `TVPlayoutPRO.exe`

## Compatibilidad

- Sin migración de BD.
- Sin cambios en la UI.
- Si tenés un mpv muy viejo (< 0.36), el formato viejo del VU
  podría no funcionar. En ese caso actualizá mpv.
