# Nexora Air V25.0.0 — un solo player, nueva identidad

## Una identidad propia

TVPlayout PRO evoluciona a **Nexora Air**. La versión mayor renueva el nombre,
el icono, el ejecutable (`NexoraAir.exe`), el instalador, las ventanas, la
fuente NDI, los diagnósticos y la documentación sin perder la biblioteca ni la
configuración existentes.

El nuevo símbolo representa una señal continua que orbita un núcleo al aire:
cian y violeta para el flujo digital, con el punto rojo de transmisión.

## El que emite, manda

En el modo **Reloj del sistema**, Nexora Air ya no mantiene un reloj de pared
independiente del proceso que transmite. La primera salida FFmpeg activa es el
**player master**:

- La posición de la playlist sigue el `time=` real de FFmpeg.
- La latencia de abrir un archivo o conectar a RTMP/SRT no cuenta como contenido
  emitido.
- Si la salida se congela, la playlist se congela en el mismo segundo: no salta
  contenido y no marca como emitido algo que no salió.
- El evento termina únicamente cuando FFmpeg confirma el fin del clip.
- Tandas, loop, modo manual y reanudaciones siguen siendo decisiones del
  controlador; los workers esperan esa decisión en lugar de avanzar solos.
- Con varios destinos, uno solo es la referencia canónica y los demás siguen
  sus saltos, evitando que relojes distintos hagan oscilar la lista.
- Sin una medición inicial o sin salida activa se conserva el fallback por reloj
  de pared para que la automatización nunca quede bloqueada.

El modo PyAV tradicional conserva su monitor local y su protección de drift.

## Instalador Windows todo-en-uno

V25 incorpora un builder reproducible para Windows x64 que prepara la
aplicación, Python embebido, PySide6, PyAV/libav y FFmpeg, y produce un único
`Setup_NexoraAir_V25.0.0.exe`.

La actualización migra automáticamente desde la instalación anterior:

- `tvplayout.db` / `nexora-air.db`
- `.env`
- `cache/`
- `logs/`

Los datos de usuario se conservan al actualizar o desinstalar. El ejecutable
portable tradicional también pasa a llamarse `NexoraAir.exe`.

## Compatibilidad

- Sigue aceptándose `TVPLAYOUT_DB`; la variable recomendada nueva es
  `NEXORA_AIR_DB`.
- Una base `tvplayout.db` existente se abre automáticamente si todavía no hay
  una base con el nombre nuevo.
- Las marcas privadas de playlists antiguas se conservan para poder importar
  listas sin conversión.
