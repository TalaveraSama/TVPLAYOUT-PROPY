## TVPlayout PRO V22 — Consola de playout estilo XPlayout

![Panel](https://raw.githubusercontent.com/TalaveraSama/TVPLAYOUT-PROPY/v22.0.0/docs/panel.png)

### Novedades
- **Interfaz rediseñada al estilo XPlayout**: cabecera con reloj, tira de transporte (PLAY / PAUSA / STOP / SIGUIENTE) con miniatura e indicador **ON-AIR**, contadores (Categoría, Duración, Posición, Restante, Resta playlist, Desfase, Codec, Siguiente), fila de modos, pestañas **GRID MODE / GRAPHIC MODE / BIBLIOTECA** con filas coloreadas por categoría (azul = al aire, lila = LISTO), botonera, VU meter + monitor mpv embebido, panel FUNCIONES, SALIDA RTMP y reloj de estación.
- **Continuidad real**: encadenado automático por eventos de mpv, modo manual con cue (Preparar), **hora exacta** con desfase, loop, autofill, tandas de publicidad, botón de **EMERGENCIA**, bloqueo de consola, playlist persistente y restauración al abrir.
- **Salida RTMP / SRT / UDP** con FFmpeg que **sigue al playout local** (mismo evento), logo PNG (posición/tamaño/opacidad), subtítulos quemados opcionales, encoders AUTO / x264 / NVENC / QSV / AMF.
- **mpv por IPC bidireccional**: posición y duración en tiempo real, VU meter, pista de audio y subtítulos por evento con preferencia de **español latino**.
- **ffprobe en segundo plano**: duración, formato, pistas y miniaturas; escáner de carpetas (locales o de red).
- **Programador** diario / semanal / mensual / trimestral con "próxima ejecución".
- Diálogos: Playlist Manager (guardar/cargar/M3U/JSON), Fuentes y Categorías, Registros As-Run con exportación CSV, Ajustes del sistema, Logo/CG, Dispositivos.
- Base de datos SQLite con **migración automática** (conserva la biblioteca existente), registro rotativo en `logs\`.
- Pruebas automatizadas (`tests\test_core.py`) y mpv simulado para pruebas.

### Instalación (Windows)
1. Descarga y descomprime **Source code (zip)** de esta página (incluye el programa completo, los `.bat` y la base de datos).
2. Instala Python 3.13 x64 (o 3.11 / 3.12) y ejecuta `INSTALL.bat`.
3. Copia `mpv.exe` en `mpv-x86_64\` y `ffmpeg.exe` + `ffprobe.exe` en la carpeta raíz.
4. Ejecuta `INICIAR.bat` (`INICIAR_CONSOLA.bat` muestra los mensajes de depuración).

Atajos: **F1** Play · **F2** Pausa · **F3** Stop · **F4** Siguiente · **F5** Preparar · **F11** pantalla completa · **Ctrl+L** bloquear.

> Los binarios de mpv y FFmpeg no se incluyen por licencia y tamaño: descárgalos de sus sitios oficiales.
