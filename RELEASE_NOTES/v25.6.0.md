# Nexora Air V25.6.0 — release reproducible y validada

## Novedades

- **Identidad de versión sincronizada:** la versión V25.6.0 queda reflejada en
  la aplicación, la documentación de build y los launchers de Windows.
- **Preparación de releases reproducible:** se incorpora
  `tools/prepare_release.py` para actualizar la versión actual sin tocar el
  histórico de notas y para detectar referencias desincronizadas antes de
  publicar.
- **Validación previa a publicación:** el modo `--check` confirma la versión
  central, la documentación de distribución y la existencia de estas notas de
  release.

## Comprobación

```bash
python3 tools/prepare_release.py --check
python3 installer/build_windows_setup.py check
```
